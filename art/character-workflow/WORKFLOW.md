# Character Art Workflow

## 1. Define Style, Look, and Feel

Use `art/character-workflow/reference/canonical-reference.png`
as the canonical reference character. Analyze only the characteristics that materially help reproduce or correct its style, such as proportions, silhouette, anatomy construction, detail density, line or outline treatment, pixel construction, shading, color treatment, facial complexity, pose conventions, rendering quality, and export requirements.

The reference remains authoritative. Written rules should clarify useful observations, not exhaustively describe every visible property.

## 2. Create Character

Start with a character description, then create the character using the canonical reference and the project style definition. The primary goal is to establish the character's design and identity. A successful first pass may still need refinement before it fully belongs in the established visual world.

## 3. Compare Against Canonical Reference

Compare `EDIT_TARGET` directly against `CANONICAL_REFERENCE` before editing the character and before final quality equalization.

Explicitly identify meaningful differences that make `EDIT_TARGET` look as though it belongs to a different visual construction or style than `CANONICAL_REFERENCE`. Diagnose the drift only; do not redesign the character during this step.

Relevant comparison points include head-to-body ratio, torso length, shoulder width and body mass, arm length, hand placement, leg length, leg thickness, knee placement, shoe size, center of gravity, silhouette, anatomy realism, facial construction, outline treatment, pixel or line construction, shading density, and rendering detail.

## 4. Refine Consistency

Edit the existing `EDIT_TARGET` to correct structural and style-construction drift identified in the comparison. Preserve its identity, face, recognizable character design, hairstyle, clothing, accessories, pose, facing direction, expression, and concept rather than redesigning it.

For One Star Pawn, if proportions drift toward natural adult anatomy, make the head larger relative to the body, shorten the torso, reduce visible neck length where appropriate, shorten and thicken the arms, shorten and thicken the legs substantially, lower the knees toward the shoes, increase shoe visual mass where needed, and compress the complete body rather than merely enlarging the head.

The goal is the same character rebuilt using the canonical reference's body-construction system.

## 5. Equalize Quality

Match the reference's rendering and detail level. Depending on the project, this may mean simplifying facial detail and shading, or adding detail, matching pencil density, increasing rendering fidelity, or matching brushwork.

Quality equalization is separate from consistency correction. It answers whether `EDIT_TARGET` is rendered at the same detail and quality level as `CANONICAL_REFERENCE`, including facial detail density, shading complexity, pixel cluster size, texture density, hair and clothing micro-detail, and rendering polish. It must not replace structural consistency correction.

The new character should feel as though it was produced by the same visual system as the canonical reference.

## 6. Approve

Repeat these stages for each additional character.
