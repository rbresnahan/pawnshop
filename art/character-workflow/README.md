# Character Art Consistency Workflow

Start with one character image that successfully defines the desired visual world. Use that image as the canonical anchor for creating additional characters that feel like they belong to the same project.

This workflow does not discover an art direction automatically. Some up-front concepting is expected: first create or select a successful reference character outside or before the repeatable workflow. Once that reference exists, the documents here help reproduce its visual language consistently.

The framework is style-agnostic. It can support chunky pixel art, NES-style sprites, hand-drawn characters, sketches, realistic rendered characters, or other approaches. The project's `STYLE.md` defines what matters.

See `WORKFLOW.md` for the repeatable process, `STYLE.md` for the current One Star Pawn direction, and `reference/README.md` for adding the canonical reference.
