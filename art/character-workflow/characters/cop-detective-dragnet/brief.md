# Cop Detective — Dragnet Style

Create a second police character for One Star Pawn.

This character is a detective rather than a patrol cop.

## Character concept

- male
- middle-aged
- serious demeanor
- plainclothes detective
- Dragnet-style influence
- wearing a suit
- wearing a fedora
- looks like a no-nonsense detective
- still belongs in the gritty, slightly exaggerated One Star Pawn world

## Visual goals

- full-body character
- same world/style as the canonical reference
- game-readable sprite
- not too realistic
- not too polished
- should feel like a companion to the existing cast, not like a separate art style
